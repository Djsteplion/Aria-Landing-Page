# Aria Landing Page

A responsive business consultancy landing page built with HTML, CSS, and vanilla JavaScript.

## Highlights

* Fully responsive across desktop, tablet, and mobile
* Responsive navigation and interactive sections
* Project category filtering
* Testimonial carousel with Swiper.js
* Contact and callback forms
* CSS animations and transitions
* Semantic HTML and accessibility improvements
* Keyboard-friendly interactions
* SEO-friendly structure
* Optimized image loading for better performance

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Swiper.js
* Font Awesome

## Structure

```text
Aria-Landing-Page/
├── css/
├── images/
├── js/
├── video/
└── index.html
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Djsteplion/Aria-Landing-Page.git
cd Aria-Landing-Page
```

Open `index.html` in your browser, or use VS Code Live Server for local development.

## Accessibility & Performance

The project has been refined with a focus on semantic HTML, keyboard navigation, accessible controls, meaningful image alternatives, responsive media, and reduced unnecessary page overhead.
